# Mint Windows downloads

Official download repository for the Mint Windows.

Website: https://mintai.pages.dev

AI access and optional cloud voice services are separate. Unsigned experimental software. Read release notes and verify the SHA-256 before installing.

## Public edition

Current public downloads require each user's own Gemini API key for AI responses. No ChatGPT/OpenAI account connection or shared key is included. Free local voice needs no voice API key. Personal account-enabled builds are not distributed here.
