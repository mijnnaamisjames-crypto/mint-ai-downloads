# Mint Windows downloads

Official downloads/setup/privacy: https://mintai.pages.dev

Mint 1.0.84 uses local Qwen3.5 4B Q4_K_M and local Dutch/English speech.
No account, API key, cloud AI/speech or AI usage bill. Approve about 2.76 GB
for model/runtime setup; voice downloads separately. Windows 10/11 x64,
16 GB RAM recommended, 4 GB free disk for AI plus app/voice storage.

Optional web excerpts: enable once in Tools & voice, Save, then current short
public questions search automatically. Off by default. Only that question goes
to DuckDuckGo, not history/files/instructions. AI stays local. Linked excerpts
are not full-page verification or guaranteed current facts. No paid API/retries.

The 4B model was slower on the test laptop. Dutch samples remained poor; no
demonstrated quality improvement. Not ChatGPT-level. Check important output.

Ten validated app/site launches, simple PNG drawings, Google/YouTube commands,
and Windows output volume. Desktop Ask first defaults; Automatic optional.
No unrestricted PC control, overwritten files or guaranteed media playback.
Opened sites use normal browser privacy rules. Cloud AI remains disabled.

Unsigned: verify release SHA-256; never disable security protections. Back up
and close Mint before updating. Existing data/old model files are retained; a
new model download is required. Uninstall preserves the profile. No personal
profiles, credentials or downloaded models are published. Older releases have
different models/privacy behavior. Experimental, no accuracy/speed guarantees.
